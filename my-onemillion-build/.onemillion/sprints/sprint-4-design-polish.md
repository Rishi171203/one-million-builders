# Sprint 4 — Design & Branding Polish

## Context
Make haus look like a product people talk about: a strong landing page (haus.com-inspired),
cohesive branding, and refined animations across the app.

## Entities & Fields
None.

## Backend / Server Actions
None.

## Frontend Pages / Components
- Polished landing: hero with animated gradient/visual, value props (3 cards: Clear verdict,
  Plain language, Any country), "how it works" steps, footer with disclaimer.
- Consistent `AppHeader`/`Footer` across pages.
- Logo/wordmark treatment; favicon; social/OpenGraph metadata.
- Micro-interactions: button hovers, card hover lift, section scroll reveals, page transitions.
- Dark-mode pass (optional if time).

## Design Notes
Premium & polished, indigo + generous whitespace. Keep it calm and trustworthy (money
product). Animations smooth and purposeful, not flashy. Respect reduced-motion.

## Acceptance Criteria
- Landing clearly communicates what haus does within 5 seconds.
- Header/footer consistent on every page.
- Animations are smooth on mobile and desktop; no layout shift.
- Lighthouse: no major accessibility/contrast failures.

## Verification Gate
Build passes; visual review on mobile + desktop widths; reduced-motion respected.

## Expected Commit Message
`Sprint 4: landing page + branding + animation polish`

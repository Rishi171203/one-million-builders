## ⚠️ Noted (not fixed): Gemini returning 503
While reading the log I saw repeated `Gemini responded 503` on `/api/advice`. **503 =
Google's Gemini service was temporarily overloaded**, not a bug in our code. Our **graceful
fallback worked exactly as designed** — every `/api/advice` still returned `200` using the
deterministic verdict text, so haus never broke for the user. It just means the verdicts
were the canned ones during that window, not AI-personalized. Worth a retry later when
Google's side recovers; if 503s persist we can add a short retry/backoff.

### Rent-vs-buy chart: investigated "buy always wins" + rebuilt for readability
Rishi reported the rent-vs-buy graph "shows buying wins every time" even when changing the
sliders, and asked for a more readable chart.

- **Not a bug (verified empirically).** Ported `computeRentVsBuy` + the India affordability
  math to a throwaway node script and swept 1,260 parameter combos: **BUY wins ~1202, RENT
  wins 58** — so the model is not rigged. For the India *sample* numbers buying wins because
  `priceMax` is savings-bound at ₹35L and the sample rent (₹28k/mo) is ≈ the loan EMI
  (~₹24.3k/mo): buying is both cheaper monthly *and* builds equity. The sliders DO recompute
  (they feed `assumptions` via `useMemo`). Renting wins at the reachable extreme **Home
  grows = 0% + Investments return = 15%** (e.g. 20y: Buy ₹44L vs Rent ₹115L). Told Rishi this
  exact setting so he can watch it flip.
- **Rebuilt the chart** (`src/components/RentVsBuy.tsx`, `NetWorthChart`, still dependency-free
  SVG). Was 320×170 with only "Year 1 / Year N" labels and no scale. Now 540×300 with: a money
  Y-axis on tidy round gridlines (`niceStep` 1/2/5×10ⁿ, honest 0-baseline), year labels +
  "Years from now →" along the bottom, a shaded band between the two lines (winner-coloured),
  the **crossover point marked** with a dashed line + "they cross ~yr N", each line's **final
  value as a coloured chip** on the right, per-year hover tooltips (native `<title>`), and a
  clearer legend. tsc clean; dev server recompiled with no errors.

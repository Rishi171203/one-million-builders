### 2. Built Feature 1 — "Save advice + history"
The advisor used to forget every verdict on refresh. Now users can save and revisit them.

**New database table** (`supabase/0002_assessments.sql`):
- `assessments` table — one row per saved verdict (country, the input numbers, status, price range, EMI, verdict text, date).
- Row-Level Security so each user only sees their own saved advice (read / insert / delete own).
- Added an `is_admin()` helper + admin-only "read all" policies, so the **admin Builder dashboard can review every user and every saved assessment**.

**Advisor page** (`src/app/page.tsx`):
- Added a **"Save this result"** button under each verdict (logged-in users). Logged-out users see **"Log in to save"**.
- Save writes the verdict to Supabase and shows a confirmation toast. Re-running the advisor resets the button so the new verdict can be saved.

**Homebuyer dashboard** (`src/app/dashboard/page.tsx`):
- Replaced the old "coming next sprint" placeholder with a real **Saved advice** list — each saved verdict shows the country, affordable price range, EMI, date, and a Ready/Rent badge.

**Admin Builder dashboard** (`src/app/admin/page.tsx`):
- Stats are now **live**: Total users, Homebuyers, Homeowners, **Saved assessments**.
- Added a **Recent activity** list showing the latest saved assessments across all users.

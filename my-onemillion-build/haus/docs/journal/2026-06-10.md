### 8. AI advice layer — LIVE (the core missing piece) 🧠
The verdicts used to be canned (deterministic text that repeated). Now the AI writes them.

**Decisions:** Rishi's rule = **free for users**. Explained free-to-user vs free-to-run; he chose **Google Gemini's free tier** (vs paid Claude/GPT). The **"hybrid"** design: our code does ALL the math (price/EMI/buy-vs-rent stays exact); Gemini only writes the *language* — and we pass the computed numbers in so it can never invent figures.

**Built:**
- `src/app/api/advice/route.ts` — a **server route** (key stays server-side, never in the browser). Recomputes the math, asks Gemini for `{verdict, nextSteps}` as structured JSON, and **gracefully falls back** to the deterministic text if the key is missing / quota is hit / anything fails. haus never errors.
- Advisor `page.tsx` — `onSubmit` now calls `/api/advice`, swaps in the AI verdict + next steps, and shows a **"✨ Personalized by AI"** chip when the text is genuinely AI-written.
- `GEMINI_API_KEY` added to `.env.local` (git-ignored, server-only).

**Two gotchas we solved (noted for future):**
1. The key works, but `gemini-2.0-flash` had **free-tier quota = 0** (429). Switched to **`gemini-2.5-flash`**, which has free quota. (Overridable via `GEMINI_MODEL`.)
2. `2.5-flash` is a *thinking* model — its hidden reasoning ate the output budget and truncated the JSON. Fixed with `thinkingConfig.thinkingBudget = 0` + a larger `maxOutputTokens`.

**Verified:** real call returns `source:"ai"` with a warm, personalized verdict that references the buyer's actual income/savings/rent and uses our exact numbers. tsc clean; landing serves 200.
